# Membase 1.x Python SDK (frozen)

This repository holds the frozen 1.x Python SDK. It stays online so existing integrations keep resolving, and it gets no new features.

**Current Membase lives at [unibaseio/membase](https://github.com/unibaseio/membase).** Membase is a long-term memory layer for AI agents: one memory shared by Claude Code, Cursor, Codex, ChatGPT and your own agents over MCP. It runs hosted or locally on your own machine.

- Website: https://membase.com
- Docs: https://docs.membase.com
- Python: `pip install unibaseio-membase`
- TypeScript: `npm install @unibaseio/membase`

The 1.x usage notes are kept in this repository's [history](https://github.com/unibaseio/membase1.0-sdk/blob/aa88eb33df10973a8def142532e7d2693cd2ff43/README.md).
